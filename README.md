
# 🎬 Movie Recommender System

A simple **Movie Recommender System** built in Python that suggests movies based on user preferences using movie genres and a similarity model.

---

## 🔍 Project Overview

This project allows users to get movie recommendations by selecting a movie they like. The system uses a content-based filtering approach to suggest similar movies.

**Key Features:**
- Suggests movies based on user-selected title.
- Uses TF-IDF vectorization on movie genres.
- Fast and easy to use.
- Simple Streamlit web interface for interactive usage.

---

## 🛠️ Technologies Used

- Python 3.x
- Pandas
- Numpy
- Scikit-learn
- Streamlit
- Pickle (for saving the model and movie dictionary)
